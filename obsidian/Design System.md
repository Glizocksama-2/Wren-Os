# Design System (Stitch Archetype)

## Typography
- Display Font: `Outfit` (700-900, letter-spacing `-0.025em`)
- Body Font: `Outfit` (400, line-height `1.65`, 65ch max-width)
- Banned: `Inter`

## Color Palette
- Base: Slate Blue / Dark Steel Theme
- Primary Accent: Stitch Blue (`#1E3A8A`)

## Borders & Layout
- Card radius: `2.5rem`
- Card shadow: Diffused wide spread (`0 20px 40px -15px rgba(0, 0, 0, 0.3)`)
- Layout structure: Asymmetric grid (Bento pattern)
